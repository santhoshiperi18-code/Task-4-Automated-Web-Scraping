# Task 4 - Automated Web Scraping & Data Extraction Pipeline

## Objective

Build an automated ETL web scraper using Python, Requests,
and BeautifulSoup to extract structured data from a public website.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV
- JSON

## Features

- Web scraping
- Custom headers
- Retry logic
- Rate limiting
- Data extraction
- Data transformation
- CSV and JSON output
- Automated summary statistics
